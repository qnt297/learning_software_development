# learning_software_development

ソフトウェア開発・設計を学ぶための教材リポジトリです。

## コンテンツ

| パス | 内容 |
|------|------|
| [java/](java/) | Java 開発の学習ロードマップ・教材・サンプルコード |
| [db/](db/) | データベース（PostgreSQL / SQL）の学習ロードマップ・SQL 演習 |
| [docker/](docker/) | 研修用 Docker Compose（JDK / PostgreSQL / Eclipse 連携手順） |

## おすすめの進め方

1. [docker/README.md](docker/README.md) で実行環境を起動する（Eclipse はホスト側）
2. [java/README.md](java/README.md) で言語・設計・Spring / JDBC まで
3. 並行またはその後に [db/README.md](db/README.md) で SQL／RDB 基礎

## ブランチ

- `main` … 安定版
- `dev` … 教材・サンプルの開発ブランチ
