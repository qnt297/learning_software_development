# learning_software_development

ソフトウェア開発・設計を学ぶための教材リポジトリです。

## コンテンツ

| パス | 内容 |
|------|------|
| [java/](java/) | Java 開発の学習ロードマップ・教材・サンプルコード |
| [db/](db/) | データベース（PostgreSQL / SQL）の学習ロードマップ・SQL 演習 |

## おすすめの進め方

1. [java/README.md](java/README.md) で言語・設計・Spring 概要まで
2. 並行またはその後に [db/README.md](db/README.md) で SQL／RDB 基礎
3. Java の永続化（JDBC / JPA / Spring Data）へ接続

## ブランチ

- `main` … 安定版
- `dev` … 教材・サンプルの開発ブランチ
